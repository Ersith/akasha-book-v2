# 门控（akasha-gate）：设计原则与边界清单

> 2026-10-11 立。来源：把「从 CyberStrikeAI 借鉴」的条目落成可执行的纪律（B4 原则成文 + B8 边界清单）。
> 配套：`dsh-akasha-gate/index.js`（规则工厂）、`akasha/tools/gate-dry.mjs`（试匹配）。

## 一、原则（**写死，防复发**）

1. **守卫优先于一切许可**：门控的判定**不受**任何"审批通过 / 白名单 / 关闭提示 / 用户口头同意"影响——它只看**这次调用本身**。想绕过只有一条路：**停用插件**（并在日志里留痕）。
2. **拦截独立于成败口径**（B4）：被门控拒绝的调用**不计入**"任务失败"或"成功率"分母（用于我们的观察口径与漏召率统计）；拦截有**独立状态**与独立计数。**理由**：把守卫拒绝算作失败会污染度量、并诱导"为了指标而放行"。
3. **单一判据来源**：门控与试匹配（`gate-dry`）**共用同一份规则工厂** `createGateRules()` ⇒ **"试匹配说会拦就一定拦，说会放行就一定放行"**；禁止在别处复制一份规则。
4. **规则有序、首命中决定、每条有 `ruleId`**：`ruleId` 必须进日志（`gate-denied` 带 `ruleId`；启动线 `gate-armed` 带 `rulesVersion`），便于审计、复盘与回归定位。
5. **判定面**：工具名 + **路径类字段（含嵌套/数组）** + **命令全文（百分号解码 ≤3 轮）** + 委派 prompt（写动作词 + 数据区路径）。
6. **收窄优先于扩张**：宁可漏一点也不制造假阳性——**正文里"提到"数据路径不算写目标**（已有专门用例钉死）。每次"因误拦而加宽/收窄"都必须**同时补一条测试**。
7. **自身异常一律放行**：门控自崩不得拖垮宿主（`try/catch` → 放行）；但**静默降级必须有痕**（写日志）。
8. **规则变更＝代码变更**：规则在代码里，因此**变更必须走提交 + canon 条目**（谁改的、为什么、影响面），并**重跑 selftest**（含回归用例）。

## 二、我们**守不住**什么（边界清单 · 诚实版）

| # | 守不住的面 | 说明 / 已知例 |
|---|---|---|
| 1 | **WSL 挂载路径** | 同一文件在 WSL 里是 `/mnt/h/…`，而门控只认配置里的盘符形态 `H:\…` ⇒ **WSL 侧写库拦不住**（代码里有注释；要覆盖需加 POSIX 形态的 dataDir 配置项） |
| 2 | **任意编码** | 已收窄**百分号编码（≤3 轮）**，但 **base64 / 十六进制 / 变量拼接 / 字符转义** 仍可绕过（我们只做"劝告层"） |
| 3 | **间接执行** | 门控只看**工具参数文本**；命令里再调用脚本文件、脚本里再写数据，**不在覆盖范围** |
| 4 | **未登记的工具** | 只覆盖 `WRITE_TOOLS` / `SHELL_TOOLS` / `AGENT_TOOLS` 三张表；**新增写盘工具必须同步登记**（否则是盲区；历史教训：`dsh_wsl`、codex 系曾漏） |
| 5 | **文件系统层面的旁路** | 别的进程（Notepad、Explorer、其他 App）改 JSONL 不经过我们；门控只作用于**经本宿主的工具调用** |
| 6 | **语义级污染** | 它只防"直改文件"，**不防**"用 CLI 写入一条语义错误的记录"——那要靠审计与修订链 |
| 7 | **权限/管理员动作** | 门控不拦系统级命令（关服务、改注册表等）；这类属于运维范围，靠 runbook 与审计，不靠守卫 |

> **一句话**：门控是**劝告层**（降低误操作概率、留痕、纠偏），**不是安全边界**；真正的边界是备份、权限、容器/隔离与审阅。

## 三、怎么用（日常）

```powershell
# 试匹配：只报判决，不拦任何东西（exit 0=放行 / 3=会拦）
node <AKASHA_DIR>\tools\gate-dry.mjs --tool edit --json '{"file_path":"<AKASHA_DIR>\\data\\canon.jsonl"}'
node <AKASHA_DIR>\tools\gate-dry.mjs --tool pwsh --command "echo x >> <AKASHA_DIR>\data\canon.jsonl"
Get-Content case.json -Raw | node <AKASHA_DIR>\tools\gate-dry.mjs --stdin
# 回归：改规则后必跑
node <LOCAL_PATH>\dsh-akasha-gate\selftest.test.mjs
```
