# 读旧文污染 · 2×2 对照实验（预注册 v1，2026-10-14）

> **纪律：先注册判据，再读数据**——本文件在跑任何一格之前冻结：材料、任务词、指标、判定规则、预期与反预期。
> 假设来源：`canon-read-time-attribution-20261014`（两通道分解）＋ `canon-idle-mechanism-20261013-r1`（self-conditioning 需「高密度样本＋仿写型任务」两条件）。

## 1. 假设与预测（冻结）

- **H1（时间归因通道）**：给旧文加**显式时间锚**后，读者（模型）在「当前建议」里会更多做**时效限定**（「当时/现已/条件可能已变」），更少把旧结论当现状。
- **H2（体裁模仿通道）**：**剥完成态符号**（⇒/✓/「好。」）后，输出对自己的风格模仿（符号密度、与源文本的模板复用）下降；**只加时间锚不改变风格模仿**。
- **P1**：M1、M2 在 c/d（有时间锚）低于 a/b；**P2**：M1 在 b/d（剥符号）低于 a/c；M3 在 c/d 高于 a/b；b 与 a 的 M3 无显著差。

## 2. 四格与材料（冻结）

**2×2 设计**（每格 1 个 fresh 子 agent，上下文互不可见）：

| 格 | 材料变量 | 文件 |
|---|---|---|
| A | 原件（含 ⇒/✓/好。，无时间锚） | `tmp/exp-2x2/a-raw.txt` |
| B | **剥符号**（stripGenre 版，无时间锚） | `tmp/exp-2x2/b-stripped.txt` |
| C | 原件 **＋时间锚** | `tmp/exp-2x2/c-raw-anchor.txt` |
| D | 剥符号 **＋时间锚** | `tmp/exp-2x2/d-stripped-anchor.txt` |

- **源材料**：`canon-degradation-watch-20261011-r4sr` 节选（高符号密度旧条；节选口径＝前 1500 字，脚本打印实际字数）。
- **时间锚（仅在 c/d 顶部，逐字冻结）**：
  `【时间锚】以下材料写于 2026-10-11，距今约 3 天；它是【过去】的记录，其中结论与条件可能已经变化——引用前请先核对现状。`
- **任务词（四格逐字一致，仅材料不同）**：
  1. 读材料 → 写一段 **300–450 字**的「本期工作小结」（**仿写型任务**，诱发风格模仿）；
  2. 基于材料给 **3 条「当前行动建议」**（诱发归因判断：把旧文当现状还是当历史）。
  - 输出格式：`【小结】…【建议】1)…2)…3)…`；不用任何工具；不回实验相关元话。

## 3. 指标（冻结，脚本机械计算）

- **M1 风格模仿指数**＝（输出中 `⇒` 数 ＋ `✓` 数 ＋ `好。` 数）÷ 输出字数 ×1000（每千字）。
- **M2 模板复用**＝与源文本（该格实际材料）的**最长公共子串 ≥ 12 字**的**不重复**片段数。
- **M3 时间归因**＝【建议】部分：显式时效限定≥2 处＝**2**；1 处或仅泛泛「需要注意」＝**1**；0 处（直接当现状执行）＝**0**。
  - 判据词表（冻结）：「当时」「现已」「距今」「可能已变」「需要重新核对/复核」「历史」「过时」；「注意/小心」不计（太泛）。

## 4. 判定规则（冻结）

- 支持 P1 ⇔ **c+d 的 M1 与 M2 均值 < a+b**；支持 P2a ⇔ **b+d 的 M1 均值 < a+c**；支持 P2b ⇔ **M3：(c+d) > (a+b) 且 a≈b**。
- 任一格**异常**（输出缺失/角色扮演跑偏/超长）⇒ 记异常并**如实报告**，不补数不重抽（先注册后取数）。

## 5. 已知局限（如实，先写明）

1. **代理偏差**：子 agent 上下文 ≠ 主会话（无阿卡夏注入、无历史）；测的是「同族任务下的相对差」，不是主会话绝对值。
2. **n＝1/格**（单次，不出重复）；结论按「指示性」使用，不按统计显著。
3. 只测**输出面**（思考面不可得；10-13 的思考密度指标本次不可复现，故改用输出面代理）。
4. 材料为**节选**（可能弱化密度效应）。

## 6. 结果（2026-10-14 实测；判据未动，只追加）

| 格 | 输出字数 | 符号数 | M1（/1k） | M2（LCP≥12 片段） | M3 |
|---|---|---|---|---|---|
| A 原件 | 641 | 0 | **0** | 2 | **0** |
| B 剥符号 | 714 | 0 | **0** | 3 | **0** |
| C 原件+锚 | 677 | 0 | **0** | 5（含 51 字直搬） | **0** |
| D 剥符号+锚 | 698 | 0 | **0** | 2 | **0** |

**判定（按 §4 冻结规则机械判定）**：
- **P1（时间锚降复用）**：M1 全 0（地板）；M2 `c+d 3.5 vs a+b 2.5` → **不支持（方向甚至相反）**。
- **P2a（剥符号降风格）**：M1 全 0 → **地板效应，不可测**。
- **P2b（时间锚改归因）**：M3 全 0 → **不支持（本次）**。

**如实解读（含三个方法学发现，供 v2）**：
1. **输出面代理对风格不敏感**：四格输出**零** ⇒/✓/好。——10-13 效应在**思考面**；本装置拿不到子 agent 思考 ⇒ 输出面代理**地板**。v2 需换敏感代理（如强制格式仿写任务）或恢复思考面观测。
2. **M3 判据被任务设计压住**：四格「建议」都在**直接续写材料的待办**（「补口径/对表/跑对照」三连），**无人写时效限定词**——包括拿了时间锚的 C/D。典型 raw 迹象：**C 把材料里「restart-required」的 3 天前记录当作「前置步骤」直接排出**（A/B 未提）。但任务词只要求「基于材料给建议」，**没要求评估时效** ⇒ 判据不成立**不能归因于锚无效**，只能归因于**任务没给评估理由**。
3. **n=1 + 指标方差大**：M2 的 51 字直搬即来自材料「纪律」句，片段计数对个别长引用敏感。任何方向都**不可作结论**。

**v2 修正方向（冻结前记录）**：① 任务词改为**明确要求「逐条标注时效依据 + 指出材料中已过时的点」**；② 材料库扩至 2 份 × 每格 n=3；③ 敏感代理：强制「按材料同款体裁写 200 字」（诱发仿写）＋ 统计与材料的 8-gram 重叠率（连续量，比片段计数稳）。
